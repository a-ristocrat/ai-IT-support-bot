Symptoms: "No internet", Wi-Fi connected but pages won't load, Wi-Fi keeps dropping.

Check that other devices can use the same Wi-Fi. If none can, the problem is the network — escalate.
Turn Wi-Fi off and on, or toggle Airplane mode.
Forget the network and reconnect: Settings > Network & internet > Wi-Fi > Manage known networks.
Run the network troubleshooter: Settings > System > Troubleshoot > Other troubleshooters.
Reset the connection in Command Prompt: ipconfig /release ipconfig /renew ipconfig /flushdns
Restart the computer.
If it still fails, escalate with a ticket.
