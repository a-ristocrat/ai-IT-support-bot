Symptoms: Outlook won't open, emails not sending/receiving, keeps asking for password.

Check internet connection and that Outlook is not in "Work Offline" mode (Send/Receive tab).
Close Outlook fully and reopen it.
If emails are stuck in the Outbox, check for very large attachments (over 20 MB) and remove them.
If Outlook keeps asking for a password: close Outlook, open Credential Manager in Windows, remove saved Office/Outlook entries, then reopen Outlook and sign in.
Try Outlook on the web to see if the problem is the account or the app.
If Outlook won't open at all, start it in safe mode: press Win + R, type outlook.exe /safe
If it still fails, escalate with a ticket.
